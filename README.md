# Supero plugin for Claude Code

This repository is a Claude Code plugin marketplace with one plugin, `supero`. It connects Claude Code to [Supero](https://supero.dev), a platform for building and deploying multi-tenant web apps, so that a request such as "Build a support portal on Supero" goes straight to Supero's build tools.

## What it installs

- **The Supero MCP server**, declared in [`plugins/supero/.mcp.json`](plugins/supero/.mcp.json): `https://mcp.supero.dev/mcp`, over streamable HTTP. You sign in with your Supero account through OAuth. There is no API key to copy, and the plugin stores no credentials of its own.
- **One skill, `supero-build`**, in [`plugins/supero/skills/supero-build/SKILL.md`](plugins/supero/skills/supero-build/SKILL.md). When you ask Claude to build, change, deploy or inspect an app on Supero, it tells Claude to use the Supero tools, to ask you to sign in through `/mcp` if you haven't yet, and to confirm with you before any publish, deploy or delete.

The plugin has no hooks, no scripts and no local executables. Claude Code connects to `mcp.supero.dev` when a session starts, to load the server's tools and handle sign-in, and again when it calls one of them. Sign-in opens `app.supero.dev` in your browser.

## Install

Inside Claude Code:

```text
/plugin marketplace add supero-platform/supero-claude-plugin
/plugin install supero@supero
```

Or from your shell:

```bash
claude plugin marketplace add supero-platform/supero-claude-plugin
claude plugin install supero@supero
```

Then run `/reload-plugins` in Claude Code, or restart it.

On Claude Code v2.1.275 or later you can do both in one step inside Claude Code:

```text
/plugin install supero --marketplace supero-platform/supero-claude-plugin
```

It adds the marketplace after you confirm, then opens the plugin's details page, where you pick an install scope.

## Sign in

1. Start Claude Code and run `/mcp`.
2. Select the `supero` server (listed as `plugin:supero:supero`) and choose to authenticate.
3. Your browser opens the Supero sign-in page. Sign in, choose a new or an existing project for Claude Code to work in, and whether it may publish apps.
4. Back in Claude Code, `/mcp` shows the server as connected.

You can review or revoke the connection at any time at `https://app.supero.dev/oauth/connections`. If you don't have an account yet, sign up at [app.supero.dev](https://app.supero.dev).

Non-interactive runs (`claude -p`) can't open the browser sign-in. Sign in once in an interactive session first.

## Manual setup without the plugin

The plugin only saves you this step. To add the server yourself:

```bash
claude mcp add --scope user --transport http supero https://mcp.supero.dev/mcp
```

Without `--scope user`, the server applies to the current project only. Then run `/mcp` and sign in as above.

Use one or the other: with both, the same tools appear twice. To drop the manual entry, run `claude mcp remove supero`; to drop the plugin's, disable the plugin.

## Set it up for a whole team

Commit this to your repository as `.claude/settings.json` (also in [`examples/team-settings.json`](examples/team-settings.json)):

```json
{
  "extraKnownMarketplaces": {
    "supero": {
      "source": {
        "source": "github",
        "repo": "supero-platform/supero-claude-plugin"
      }
    }
  },
  "enabledPlugins": {
    "supero@supero": true
  }
}
```

When a teammate opens the repository in Claude Code and accepts the workspace trust dialog, Claude Code registers the `supero` marketplace and lists the plugin as enabled for the project but not installed. In an untrusted folder the marketplace entry is ignored. Each teammate then installs it once per clone:

```bash
claude plugin install supero@supero --scope project
```

Then run `/reload-plugins` or start a new session.

Each teammate still approves the plugin's MCP server and signs in with their own Supero account through `/mcp`. Nothing in the settings file is a secret.

Administrators who manage Claude Code for an organization can put the same two keys in managed settings instead. Claude Code then registers the marketplace and installs the plugin on each managed machine at the next session start.

## App folders

Apps generated by Supero can also carry a project-level `.mcp.json` (see [`examples/app-folder.mcp.json`](examples/app-folder.mcp.json)). When you open such a folder in Claude Code, it asks whether to use the Supero server for that project. The file holds only the public server URL: no key, domain or project id.

Before approving, check that the server URL is `https://mcp.supero.dev/mcp`. If an app folder's `.mcp.json` names any other URL, don't approve it.

## Updates

The plugin sets a `version`. Each release raises it. Run `claude plugin update supero@supero` to update, or turn on auto-update for the `supero` marketplace in `/plugin` under **Marketplaces**.
